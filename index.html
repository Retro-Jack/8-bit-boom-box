8-Bit Boom Box

A cassette deck for an emulated 8-bit machine. The machine below is a stand-in: it does not emulate anything, it just behaves the way a tape-loading machine behaves, so the deck has something real to react to.

Try this

  1. Insert the 3-file tape, then type the load command and press play on the deck.
  2. Watch the reels turn and the bar fill. The motor stops between blocks and the readout says Please wait.
  3. When the first file is in, the machine returns to its prompt and the deck says so — it will sit there until you type the command again.
  4. Press eject with a tape in to empty the bay, and the deck shows its own mechanism instead of a cassette.
